# Tonally skills

Skills for AI coding agents (Claude Code, Cursor, Codex, Gemini CLI, GitHub Copilot and others) that work with [Tonally](https://tonal.ly), the Chrome add-on that suggests replies on X in your own voice.

```
npx skills add Tonally-ai/skills
```

Then ask your agent: *"Make me a Tonally voice."*

| Skill | What it does |
| --- | --- |
| [tonally-voice](skills/tonally-voice/SKILL.md) | Makes a voice for your own replies, one to sell in Tonally's voice marketplace (with its listing), or improves one you exported from Tonally. It interviews you, studies writing samples you point it to, tests the voice on sample posts, checks it with a script, and saves a file you paste into Tonally (Settings → Voice Profile → Add a voice from text). |

No agent? The same interview works as a prompt in any AI chat: [tonal.ly/voice-format](https://tonal.ly/voice-format).
